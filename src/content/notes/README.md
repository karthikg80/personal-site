This public repository file keeps the notes content collection initialized. It
is documentation, not a note, and is permanently excluded by the dual
publication gate.

Working drafts and raw observations do not belong here. Copy only an approved,
publishable note into this directory, then follow the release steps in
`docs/editorial-and-privacy.md`.
